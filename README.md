# 🎵 Rythm Macho!

## 🎮 개요
 - 게임 장르: 캐주얼 리듬 게임
   * 한때, 유행 했던 유투브 컨텐츠 '가짜사나이'와 리듬게임을 접목시킨 패러디 게임
 - 플랫폼: PC
 - 플레이 인원: 1인
 - 1인 개발
 - **게임의 목표**: 무싸트 훈련을 받게된 플레이어는 조교의 구령에 동작을 정확히 맞추어 모든 무싸트 훈련과정을 수료해야한다!
 - **구현 내용**:
   > + **Python**을 이용하여 2D 리듬 게임 개발
   > + **이미지 리소스 모두 자체 제작**
   > + **사운드**(배경음, 효과음), 다시도전 기능
 - 개발에 사용된 기술 스택:
   + Python
 - 시연 영상: [▶️ 유투브 영상 보기](https://www.youtube.com/)
