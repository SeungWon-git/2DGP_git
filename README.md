# 🎵 Rythm Macho!

## 🎮 개요
 - 게임 장르: 캐주얼 리듬 게임
   * 한때, 유행 했던 유투브 컨텐츠 '가짜사나이'와 리듬게임을 접목시킨 패러디 게임
 - 플랫폼: PC
 - 플레이 인원: 1인
 - 1인 개발
 - **게임의 목표**: 무싸트 훈련을 받게된 플레이어는 조교의 구령에 동작을 정확히 맞추어 모든 무싸트 훈련과정을 수료해야한다!
 - **구현 내용**:
   > + **Python**을 이용하여 2D 리듬 게임 개발
   > + **이미지 리소스 모두 자체 제작**
   > + **사운드**(배경음, 효과음), 다시도전 기능
 - 개발에 사용된 기술 스택:
   + Python
 - 시연 영상: [▶️ 유투브 영상 보기](https://www.youtube.com/)

## 📝 어려웠던 점
   
### ⏱️ 싱크 맞추기
- 리듬 게임이므로 **정확한 타이밍 체크가 중요**하므로, delta_time을 사용하여 실제시간을 측정해 **초당 프레임을 정하여 애니메이션을 항상 일정하게 재생**시킨다.
  - 이를 통해, pt 체조에서 손을 완전히 내리는 *동작이 나오는 정확한 타이밍에 구호를 외치는 것을 측정* 할 수 있게 됨.
* 관련 코드: [pt체조 타이밍 체크](https://github.com/SeungWon-git/2DGP_git/blob/7dd94b6303096522e54bf435059827f82f0839ca/%EA%B8%B0%EB%A7%90%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/%EB%A6%AC%EB%93%AC%20%EC%82%AC%EB%82%98%EC%9D%B4/stage1.py#L856C9-L856C22)
  
### 🎨🖌️ 스프라이트 이미지 자체제작
- 패러디 게임을 만들다 보니 자체제작하여 만들어야 할 스프라이트 이미지들이 많이 필요하였다. 이에 간단한 픽셀 스프라이트 이미지들을 만들 수 있는 [픽셀앱](https://www.piskelapp.com/) 이라는 사이트를 이용하여 제작하였다.
- 또한, '리듬천국' 이라는 게임을 참고하여 게임을 만들었기에, 다양한 상황별 캐릭터들의 반응과 대사를 만들었는데, 예를 들면 본인 캐릭터가 실수하여 구호 타이밍을 놓치거나 실수하면 자신의 캐릭터는 곤란해하고 다른 동료들은 짜증을 내는 반응을 만들었다.
* 관련 코드: [Resource 폴더](https://github.com/SeungWon-git/2DGP_git/tree/7dd94b6303096522e54bf435059827f82f0839ca/%EA%B8%B0%EB%A7%90%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8/%EB%A6%AC%EB%93%AC%20%EC%82%AC%EB%82%98%EC%9D%B4/res)
